# Spendo — Erasmus Expense Tracker

A mobile expense tracking app built for Erasmus and international students.
Developed with Flutter as part of the Mobile Application Development course at Altinbas University (2026).

## Features
- Track daily expenses with categories (Food, Transport, Housing, Fun, Health)
- Monthly budget tracking with progress indicator
- Spending breakdown with donut chart and category bars
- Live currency converter (TRY, EUR, RON, USD, GBP and more)
- Multi-currency support — set your local currency in Settings
- Local SQLite database — works fully offline

## Tech Stack
- Flutter & Dart
- SQLite (sqflite)
- SharedPreferences
- ExchangeRate API (live currency rates)
- fl_chart (donut chart)
